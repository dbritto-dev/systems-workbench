# Translating a lesson to Spanish

Pilot: `lessons/queues` (the reference implementation). The page ships both languages and CSS shows one. `?lang=es|en` sets it, then the reader's last choice, then the browser.

## Conventions

- **Title:** `"<Concept> Workbench"` → `"Banco de trabajo: <concepto en minúscula>"`, e.g. "Banco de trabajo: colas", "Banco de trabajo: cachés".
- **Eyebrow:** `"Systems lesson NN · X"` → `"Lección de sistemas NN · X"`.
- **Style:** neutral Latin American Spanish, *tú* form, as short and direct as the English. No regionalisms (no *vosotros*, no *ordenador*, no *coger*).
- **Terms:** use the word Latin American developers say: cola, pila, caché, reintento, productor, consumidor, rendimiento (throughput), latencia, handler, ack, idempotente.
- **English names people search:** keep them, with a Spanish gloss the first time they appear in a text, e.g.:
  - "cola de mensajes muertos (dead-letter queue, DLQ)"
  - "tiempo de invisibilidad (visibility timeout)"
  - "bloqueo en la cabeza de la fila (head-of-line blocking)"
  - "búfer circular (ring buffer)"
  - "ley de Little (Little's law)"
  - "al menos una vez (at-least-once)"
- **Numbers:** decimals with a point (`1.5 s`), units unchanged, results never edited by hand.
- **Words on the machine:** short, UPPERCASE, and the same word as the matching panel stat. Shorten the Spanish rather than shrink the type below the English size:
  - DONE → HECHOS, DONE TWICE → DOS VECES
  - DEAD LETTERS → MENSAJES / MUERTOS (two lines)
  - TURNED AWAY → SIN / LUGAR (two lines)

## Checklist

1. **Imports:** `import { t, tx } from "../../workbench/page.mjs"` in `build.mjs`, and `import { t } from "../../workbench/i18n.mjs"` in `figure.mjs` if the machine has words on it.
2. **Wrap every reader-facing string in `t(en, es)`:**
   - page: title, eyebrow, lede, `machine.intro`, `predict.intro`, `explain.intro`, footer (the default footer is already bilingual, so drop a custom one unless it says more);
   - figure plate: title, keys, caption, hint, readout;
   - panel: stats labels, seg labels and option texts (plain numbers like `"0.3/s"` stay plain), actions;
   - experiments: title, change, question, every option, why;
   - questions: both halves of each `[q, a]`.
3. **Raw HTML a lesson appends** (a note under the panel, extra markup) goes through `tx(t(…))`. A bare string stays English.
4. **Stage aria-label:** pass `stageLabel: t(en, es)` to `figurePlate` (it adds `role="img"` and an aria-label that follows the switch) instead of writing `aria-label` into the `stage` string.
5. **SVG aria-label:** `k.figureSvg({ label: t(en, es), … })` takes a bilingual label (workbench/kit.mjs wraps the kit's figureSvg).
6. **Words painted on the machine:** pass `t()` to `faceText` or any part that prints through it (`label(…)` helpers, card, sign, plaque, dial label, slipText). Then screenshot ES and check every word fits its face. Spanish runs about 20% longer.
7. **Live text in the script** (`readout`, stats set with `textContent`, button labels):
   - Use `WB.T(en, es)` for bilingual values and `WB.L` to pick (`const { T, L } = WB;`).
   - Store messages as `T(…)` objects (e.g. a `note` shown for a few seconds) and call `L()` only when writing to the DOM. Then a message created in English shows in Spanish after a switch.
   - Compose sentences per language. Don't concatenate translated fragments: word order differs ("parcel 45 waits on the rack" → "el paquete 45 espera en el estante").
8. **Redraw on switch:** `WB.onLang(() => { …relabel pause button…; paint(0); if (loop.paused) say(L("paused", "en pausa")); })`. A paused figure doesn't repaint on its own, so the readout, stats and Play/Pause label would stay in the old language.
9. **`onPause`:** the Play/Pause label and "paused" go through `L()`.
10. **Experiment `RUNS`:** return `verdict: T(en, es)` and bars as `[T(label), share, textOrT, after]`. The card re-renders on switch. Build both sentences from the same numbers.
11. **Verify:** `NODE_PATH=<node_modules with playwright> CHROMIUM_PATH=… node tools/i18n-check.cjs lessons/<slug>/<page>.html <outDir>` runs the checks below and exits non-zero on a problem; then read its screenshots yourself:
    - `?lang=es` and `?lang=en`, light and dark: 0 console errors; `scrollWidth` 390 at 390 px.
    - Run all five experiments in ES: verdicts and bars are Spanish. Switch to EN: they re-render.
    - Switch mid-animation (the readout follows), then pause and switch (the readout and the Play/Pause button follow).
    - Collect visible text nodes (HTML + SVG, skipping `display:none` ancestors) plus aria-labels and `document.title` in both languages:
      - ES strings identical to EN are untranslated, except "Auto", "Fig 1", "Anatomy", numbers and letters.
      - EN strings with accents or Spanish words are leaks.
      - Grep the ES list for English stopwords; what's left should be deliberate glosses.
    - Screenshot the figure in ES light and dark and read every painted word.

## Pitfalls

- **Bilingual `faceText` draws two `<text>` nodes.** Use it only for static words. For a face text the script updates (parcel numbers, slip values), keep one `<text>` and set it with `WB.L`.
- **Strings built from numbers** (`"parcel " + id + " failed"`) are easy to miss. Grep the live code for `"[a-z]` string literals that reach `say`, `stat` or `textContent`.
- **Status suffixes** inside a stat value (" (3 ignored)") need `L()` too.
- **Two-line labels:** check the Spanish against the face width, not the English line count. "TURNED / AWAY" became "SIN / LUGAR" because "RECHAZADOS" didn't fit at any readable size.
- **Cramped labels:** "REENTREGADOS" fits only at 1.8 units. If a word is near the edge, prefer a shorter synonym or move the label rather than shrink it.
- **Repeated translations:** experiment `change` lines and bar labels repeat the panel vocabulary. Translate the panel first and reuse the same words, so the reader can map an experiment onto the controls.
- **Inline HTML in `t()`:** `<em>` in an intro is fine (it's inserted as HTML), but `tx(v, true)` fields (experiment texts, captions) are escaped, so keep markup out of those.

- **Name clashes:** some lessons already use `T` or `L` (a timing table, a line helper). Alias the helpers instead (`const TT = WB.T`, `const tr = WB.L`); a duplicate `const` stops the whole script.

## Search lessons (35–39)

The sample documents, queries and corpora are data the models score: keep them in English so every number stays the same, and say so once in the Spanish intro ("Los documentos de ejemplo están en inglés para que las cifras coincidan con el modelo"). Translate everything around them: labels, readouts, experiments, explanations.
